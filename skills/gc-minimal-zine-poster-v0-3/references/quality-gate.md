# Quality Gate

## Generated raster

Inspect the actual full image and thumbnail, not merely the prompt.

- Requested ratio (default 3:5), open paper/cluster balance and material match style-system.md; source invariants outrank numerical allocation targets.
- One clear metaphor/event; chosen layout/focal structure/type/texture/mood, not full-scene inventory or generic template.
- Main high-chroma accent visibly survives at thumbnail scale with the prescribed role/share; muted support wording has not washed it out.
- Type participates without ad hierarchy; exact required copy is correct and legible.
- The prompt names concrete focal/color carriers. No unrequested maritime emblem, generic icon, full-bleed, ad/logo/CTA, glossy/mockup/3D/neon/cartoon/cinematic drift or dense/multicolor scrapbook.
- Reference-only identity, wording, signature/watermark, exact dates/locations and composition have not leaked into the new work.

## Photo preservation

Every image has an explicit role and the actual required reference was included in generation, not merely described.

Compare with source: edit targets/supporting inserts retain all declared identity, proportions, markings, geometry/count, pose, silhouette and recognizable colors except allowed changes. High preservation must not silently become a redrawn lookalike. Reference-only work retains requested style traits, not its subject/wording/layout. Report role, level, invariants and limitations truthfully.

On failure regenerate once, targeting the defect. For edit targets/inserts, preservation precedes metaphor/space/accent/type/texture; for reference-only, source separation precedes those choices. After a second failing result state the issue, never claim a pass.

## Analysis or prompt-only

Analysis claims must come from inspected usable files, with metadata for exact sizes, observation separated from inference, fixed/variable/residue distinction, measurable prompt behavior, grammar-level variation and honest confidence limits.

Prompt-only must include the four-paragraph compiler, content-derived relation, position/size, exact hue+carrier, print material and relevant negatives, without claiming generation or visual inspection.
