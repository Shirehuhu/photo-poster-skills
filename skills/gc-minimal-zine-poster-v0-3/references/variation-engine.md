# Variation Engine

Choose the content-derived metaphor first, then one compatible option per axis.

## Axes

- Layout: center-fragment; lower-left-float; upper-right-block; dual small panels; irregular-cutout; type-led; dot-orbit; single-specimen; diagonal-notes; edge-counterweight.
- Focal form: tiny faded photo, rectangular crop, torn clipping, flat silhouette, opaque printed block, old printed illustration, specimen, translucent overlay, texture window or fragmented type.
- Type: floating letters, edge phrase, source-supported archive/date/weather microtext, diagonal words, gray ghost text, rough letterpress type-object, block text or one tiny caption.
- Texture: xerox, risograph, letterpress bleed, halftone, native film grain, paper/scan noise, restrained aging, slight misregistration, or selective motion blur on secondary text only when allowed.
- Marks: zero to three restrained elements drawn from dot/annotation line, tiny arrow/dashes, transparent rectangle/registration, one hand curve, source-supported code label—or none.
- Paper tone/mood/accent: follow style-system.md and the content; not random objects or palette defaults.

## Discipline

Change visual grammar, not just coordinates: adjacent outputs should differ in layout family, focal-element form and typography distribution. Use visible current outputs only; do not claim unseen prior-image memory.

Do not repeatedly default to centered photo + blue dots + microtext. A centered predecessor suggests off-axis, dual-panel, type-led or edge-counterweight next, if compatible with source preservation.

For four or more outputs use at least three layout families; no repeated adjacent layout/focal pair. At least 60% should carry main color through subject, cutout, block, photo region or bold type, not a tiny dot/hairline. An internal two-fragment recipe is not permission for an original/result comparison.

Marks remain subordinate. If dense, remove marks first, then secondary text; preserve the main metaphor and accent. High-preservation people/products retain their declared geometry/identity regardless of the chosen form.

Record one compact recipe: layout / metaphor / focal form / typography / main hue+carrier / texture / marks / mood. This is an execution record, not extra prose for the image prompt.
