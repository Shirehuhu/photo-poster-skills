# Prompt Compiler

Write decisive, visible directions, not vague aesthetic labels or internal analysis. Keep the final prompt in four compact paragraphs:

1. Canvas ratio, paper/surface, no-border/mockup choice, quiet-space share, cluster size and concrete placement.
2. Input-image role/preservation/invariants/permitted changes when applicable; one content-derived visual relation, concrete focal-element carrier and material treatment.
3. Exact short text, type/spatial behavior, exact main hue, its physical carrier/material/area, optional subordinate hue, and selected print defects.
4. Flat scan/light/contrast/mood plus the shortest relevant exclusions.

The carrier is an actual photo fragment, paper cutout, ink block, specimen, printed illustration, texture window or typography—not ambiguous compositional shorthand that a model might render as an unrelated object.

## Input-specific wording

- Edit target/supporting insert: name High/Medium preservation, exact recognizable invariants, permitted changes and allowed new elements. At High, prefer original photographic/printed fragments; do not redraw people/pets/products/characters/artworks into loose illustration or silhouette without permission.
- Style reference: name only the traits to learn and require a new subject and composition; exclude its source identity, wording and exact layout.
- No photo: reduce an article/complex idea to one thesis and imageable relation, not a picture of every argument.

Use exact supplied poster text; otherwise a short phrase in the user's language or concise English fitting the mood. Keep required readable text correct and short. Longer lettering may behave as intentional texture only when exact reading is not required.

State actual position/scale. Distinguish subdued support inks from the saturated accent; do not wash out the latter. One main hue; any second hue is a tiny subordinate exception, not equal weight. Preserve protected source colors and geometry.

Name only content-supported visible objects. Non-maritime themes must not acquire ship-mooring emblems/nautical icons or generic pictograms from design jargon. When a maritime object is actually requested, describe that object's treatment, not a generic emblem.

Select relevant negatives rather than dumping a catalogue: full-bleed scene, ad/headline/CTA/logo, copied reference words/layout, glossy mockup, hard-shadow/3D/neon/cinematic drift, dense scrapbook, cartoon, multicolor chaos or unrequested icon. Include the selected photo contract and preservation protections.
