# Reference Analysis

Inspect real usable files; report missing/unreadable ones. For each, record available metadata and observed canvas, quiet-space/cluster estimates, paper tone/material, focal structure, layout, type, hue/role, marks, reproduction/light, mood and sample-specific identity/text.

Use metadata for exact dimensions/ratios; visual percentages remain estimates unless measured. Separate observed evidence from inferred intention.

Synthesize:
- fixed rules: supported by repetition across usable samples or explicitly labeled as a single-reference observation;
- variables: actual changes that preserve family resemblance, or clearly labeled proposed safe variation;
- sample residue: words/brands/signatures/watermarks, exact dates/locations, identity, objects and layouts belonging to individual examples, not reusable rules.

One reference cannot establish collection-wide frequency. Explain confidence and sampling limits.

Return a concise Chinese/English style name, one-sentence definition, observed evidence, fixed/variable systems, residue, reusable prompt, variation block, relevant avoids and limitations. The reusable prompt must express visible behavior, not just “minimal/clean.” Variation changes composition grammar, not only object position.

Do not generate when only analysis was requested. If generation is also requested, preserve the extracted fixed system and choose a new variable combination, new subject where reference-only, and a composition not copied from a sample.
